# MISCELLANEOUS TOOLS

## Overview

This is a small collection of miscellaneous standalone tools that I have built for fun or because I've needed them multiple times over the years.

## Tools

Every tool is set up to be completely standalone, single-file, with consistent theming. They need to be able to operate standalone if they are added to a user's phone 
without additional tracking or updates.

### arrows-game

My 2-year old son loves the arrows escape style games. I strongly dislike forced ads. This hasn't been fully built yet, 
but I wanted to make an arrows game for myself and for him. It will eventually include: 
- Procedurally generated seeds
- Adjustable puzzle size (rows and columns)
- Hints
- Stats

### salary-vs-hourly-calculator

For anyone who is looking at whether hourly rates would be worth more than an offered salary, vice versa, or just satisfying curiosity.
I used to use it while recruiting to help with candidate negotiations and compensation explanations.

### text-cleaner

All the little text tools to immediately clean up a body of text. White-space remover and several other options. 
Includes file name conversion to multiple case styles for repository and file naming convention normalization and standardization.

### url-cleaner

Removes pesky trailing trackers from URLs for when you are sharing links with friends or others.
